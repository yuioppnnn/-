# 就活カレンダー

就職活動の予定（エントリー締切・説明会・面接など）を管理する、ホーム画面に追加して使えるカレンダーアプリです。ビルド不要の静的サイト（HTML/CSS/JavaScriptのみ）で、GitHub Pagesなどにそのまま公開できます。

## 主な機能

- 月表示カレンダー（前月・次月・今日への移動）
- 日付をタップして予定を追加・編集・削除
- 予定の種別ごとに色分け（エントリー締切／説明会／Webテスト／ES提出／一次・二次・最終面接／内定関連／その他）
- 「今後の予定」一覧を自動表示
- データは端末のブラウザ内（localStorage）に保存
- JSON形式でのバックアップ書き出し・読み込み
- PWA対応（オフラインでも閲覧可能、ホーム画面に追加可能）

## ホーム画面への追加方法

このアプリを配信しているURLをスマートフォンのブラウザで開いた状態で行ってください。

**Android（Chrome）の場合**
1. サイトを開く
2. メニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」を選択
   ※ アプリ内のメニュー（右上の⋮）に「ホーム画面に追加」ボタンが表示された場合はそちらからでも追加できます

**iPhone / iPad（Safari）の場合**
1. Safariでサイトを開く
2. 共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択

追加後はアプリのように全画面で起動し、アイコンからすぐにアクセスできます。

## ローカルでの動作確認方法

ビルドツールは不要です。プロジェクトのルートで簡易サーバーを起動して確認してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 公開方法（例：GitHub Pages）

1. GitHubリポジトリの Settings → Pages を開く
2. Source でこのブランチ（または `main` にマージ後）とルートディレクトリを指定
3. 発行されたURLをスマートフォンで開き、上記の手順でホーム画面に追加

## データについて

予定はすべて端末のブラウザ内にのみ保存されます（サーバーには送信されません）。機種変更や別のブラウザ・端末で使う場合は、メニューの「予定をバックアップ」でJSONファイルを書き出し、新しい環境の「予定を読み込み」で取り込んでください。

## ファイル構成

```
index.html        画面本体
css/style.css     スタイル
js/app.js         カレンダー・予定管理のロジック
manifest.json     PWA設定（アプリ名・アイコン・起動方法）
sw.js             Service Worker（オフラインキャッシュ）
icons/            ホーム画面アイコン
```
